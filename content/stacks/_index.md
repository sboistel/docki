## My Own Services

I host my own services on a Raspberry Pi 5 using Docker and Docker Compose. The main services I use are:

- **Authelia**: Authentication and authorization
- **Beszel**: Custom service (details not specified) / Companion agent
- **Couchdb**: NoSQL database (Obsidian LiveSync)
- **Dozzle**: Real-time Docker log viewer
- **Dockgen**: Docker container management
- **FileBrowser**: Web-based file manager
- **FreshRSS**: RSS feed aggregator
- **Home Assistant**: Home automation platform
- **Homepage**: Custom dashboard for services
- **IT-Tools**: Collection of useful web tools
- **Immich**: Media server
- **Itunz**: Music streaming service
- **Jellyfin**: Media server
- **Kuma**: Uptime monitoring
- **Landing Page**: Main entry page
- **Linkding**: Bookmark manager
- **Navidrome**: Music server
- **Nextcloud**: Personal cloud storage
- **Nginx Proxy Manager**: Reverse proxy and SSL management
- **Octoprint**: 3D printer management
- **Rustdesk**: Remote desktop server/relay
- **Speedtest Tracker**: Internet speed monitoring
- **Stirling PDF**: PDF toolkit
- **Transmission**: Torrent client
- **Vaultwarden**: Bitwarden-compatible password manager
- **Watchtower**: Automated Docker container updates
- **Wireguard**: VPN server
