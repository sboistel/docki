## My Own Services

I host my own services on a Raspberry Pi 5 using Docker and Docker Compose. The main services I use are:

- **[AdGuard](/stacks/adguard/)**: Network-wide ad blocking
- **[Authelia](/stacks/authelia/)**: Authentication and authorization
- **[Beszel](/stacks/beszel/)**: Custom service (details not specified) / Companion agent
- **[Couchdb](/stacks/couchdb/)**: NoSQL database (Obsidian LiveSync)
- **[Dockge](/stacks/dockge/)**: Docker container management
- **[Dozzle](/stacks/dozzle/)**: Real-time Docker log viewer
- **[FileBrowser](/stacks/filebrowser/)**: Web-based file manager
- **[FreshRSS](/stacks/freshrss/)**: RSS feed aggregator
- **[Glance](/stacks/glance/)**: Dashboard and monitoring tool
- **[Home Assistant](/stacks/home-assistant/)**: Home automation platform
- **[Homepage](/stacks/homepage/)**: Custom dashboard for services
- **[Immich](/stacks/immich/)**: Media server
- **[IT-Tools](/stacks/it-tools/)**: Collection of useful web tools
- **[Itunz](/stacks/itunz/)**: Music streaming service
- **[Jellyfin](/stacks/jellyfin/)**: Media server
- **[Kuma](/stacks/kuma/)**: Uptime monitoring
- **[Landing Page](/stacks/landing-page/)**: Main entry page
- **[Linkding](/stacks/linkding/)**: Bookmark manager
- **[Navidrome](/stacks/navidrome/)**: Music server
- **[Nextcloud](/stacks/nextcloud/)**: Personal cloud storage
- **[Nginx Proxy Manager](/stacks/nginx-proxy-manager/)**: Reverse proxy and SSL management
- **[Octoprint](/stacks/octoprint/)**: 3D printer management
- **[Rustdesk](/stacks/rustdesk/)**: Remote desktop server/relay
- **[Speedtest Tracker](/stacks/speedtest-tracker/)**: Internet speed monitoring
- **[Stirling PDF](/stacks/stirling-pdf/)**: PDF toolkit
- **[SWAG](/stacks/swag/)**: Secure Web Application Gateway
- **[Transmission](/stacks/transmission/)**: Torrent client
- **[Vaultwarden](/stacks/vaultwarden/)**: Bitwarden-compatible password manager
- **[Watchtower](/stacks/watchtower/)**: Automated Docker container updates
- **[Wireguard](/stacks/wireguard/)**: VPN server
- **[WUD](/stacks/wud/)**: What's Up Docker (container update notifications)
