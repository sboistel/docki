---
title: "SAR"
description: "System Activity Report"
tags: ["linux", "sar"]
---

On trouvera les fichiers de log de l'outil **sysstat** dans : ``/var/log/sysstat/`` <br>
Chacun des fichiers dans ce dossier sera normé par ``sa$JOUR_DU_MOIS``.

Liste des paramètres :

* **S** : swap
* **r** : RAM
* **R** : Caches
* **u** : Utilisateur
